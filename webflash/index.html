Stock firmware → ZMK (two stages)

  1. Build everything first: ./build.sh -a --ansi (or --iso, add --wired for the USB-only gaming build).
  2. Keyboard in wired mode on USB with the stock firmware.
  3. Stage 1 sends the OTA bridge (build-bridge/bridge_ota.bin) over the stock OTA protocol. The keyboard reboots as "Rainy 75 Bridge".
  4. Stage 2 connects to the bridge's COM port and writes MCUboot + ZMK (build/combined.bin) to flash 0 through the bridge. The keyboard reboots into ZMK.

Already on the bridge (for example after an interrupted install)? Choose the combined image and run Stage 2 alone.

Update a running ZMK (mcumgr image upload)

Uploads build/zephyr/zmk.signed.bin to slot 1. With "test boot" the new image runs once and reverts on the next reset unless you confirm it (Tools → Confirm running image), so a broken image can never lock you out.

ZMK → stock firmware

Writes the stock OTA image to flash 0 through ZMK's flash_mgmt (staging at 0x80000, verify, commit). The calibration data above 0xFE000 is never touched. Use the image for your board (ANSI vs ISO).
